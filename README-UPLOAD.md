# Love in Lagos backend (PostgreSQL version)

Upload the contents of this folder to your backend repository (replace `server.mjs` and `package.json`).
Render settings: **Build Command** `npm install`, **Start Command** `node server.mjs`.
Required environment variable: `DATABASE_URL` (your Render PostgreSQL *Internal Database URL*).
Read `POSTGRES-SETUP.md` first: it has the step-by-step setup, the test you must run before launch, and backups.
`old-sqlite-version/` is your previous server, kept for reference only. Render does not run it.
